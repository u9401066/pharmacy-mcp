# Legacy Zotero Research Workflow Rules

Zotero/PubMed import workflows are bundled assistant references. They are not
runtime Pharmacy MCP package code, and this repository has no Zotero Keeper
server tree.

When doing literature work through installed MCP tools, preserve provenance and
ask before importing into Zotero. When doing repository work, use the Pharmacy
MCP Python gates from `.clinerules/00-project.md`.
